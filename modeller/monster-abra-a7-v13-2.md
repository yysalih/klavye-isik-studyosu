# Monster Abra A7 V13.2 — Klavye Işığı Renk Değiştirme Programı

**Monster Abra A7 V13.2** klavye ışığının rengini değiştirmek ve efekt eklemek (gökkuşağı, nefes, müziğe göre, ekran rengine göre, yazınca parlayan…) için ücretsiz, Türkçe program: **[Klavye Işık Stüdyosu](https://github.com/yysalih/klavye-isik-studyosu)**.

**[⬇️ Monster Abra A7 V13.2 için indir](https://github.com/yysalih/klavye-isik-studyosu/releases/latest)**

## Kurulum

1. [Sürümler](https://github.com/yysalih/klavye-isik-studyosu/releases/latest) sayfasından `KlavyeIsik-…-win-x64.zip` dosyasını indir.
2. Zip'i bir klasöre **çıkart** (zip'in içinden çalıştırma).
3. `KlavyeIsik.exe`'yi aç. Kurulum, .NET ya da yönetici izni gerekmez.
4. Bilgisayarda Monster **Kontrol Merkezi** kurulu olmalı (Fn tuşlarıyla klavye ışığı değişiyorsa kuruludur).

Program açılınca üst satırda modelin ve klavye türü görünür. Her şey yolundaysa şöyle bir yazı görürsün:

> Monster Abra A7 V13.2 · Tek bölge RGB · Doğrudan sürücü bağlantısı

## Windows programı engellerse

Program imzasız olduğu için Windows ilk açılışta uyarabilir; bu bir virüs uyarısı değildir.

- **"Windows kişisel bilgisayarınızı korudu"** → **Ek bilgi** → **Yine de çalıştır**
- **Düğme yoksa / açılmıyorsa** → zip'e sağ tık → **Özellikler** → **Engellemeyi kaldır** → Tamam → yeniden çıkart
- **"Tehdit bulundu" / exe kayboldu** → Windows Güvenliği → Virüs ve tehdit koruması → **Koruma geçmişi** → **Geri yükle / İzin ver**

Ayrıntılı anlatım: [Windows programı engelliyorsa](https://github.com/yysalih/klavye-isik-studyosu#windows-programı-engelliyorsa)
